# Combined MERN Project

This repository contains both the **frontend** (React + Vite) and **backend** (Node.js + Express) parts of the MERN application.

## Structure
- `Frontened-react/` – React frontend with Vite.
- `blog app backened/` – Express backend with MongoDB.

## How to Run

### Backend
```bash
cd "blog app backened"
npm install
npm run dev   # or node server.js
```

### Frontend
```bash
cd Frontened-react
npm install
npm run dev   # Vite dev server
```

## Contributing
Feel free to open issues or pull requests. Ensure both frontend and backend pass their respective linting and tests before merging.
